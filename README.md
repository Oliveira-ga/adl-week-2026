# ADL Week 2026

Site local para condução e pontuação das dinâmicas internas da ADL Week 2026.

## Objetivo técnico

- HTML, CSS e JavaScript puros
- Funcionamento offline, sem backend ou APIs externas
- Estado persistido no `localStorage`
- Interface otimizada para notebook e projetor

## Execução

Abra `index.html` em um navegador moderno. O site funciona offline e salva o andamento automaticamente no navegador.

## Funcionalidades

- Configuração de quatro times e pontuação inicial
- Placar geral, histórico e ajustes manuais
- Super Jogo da Memória com turnos e pontuação automática
- Quiz de apostas e Leilão de Enigmas com bancos de 20 itens cada
- Ordem rotativa dos times e opção de repetir ou avançar após cada dinâmica
- Cronômetro, recuperação após F5 e encerramento com pódio

## Publicação

O projeto está preparado para ser versionado no GitHub e publicado posteriormente com GitHub Pages.
