# ADL Week 2026

Site local para condução e pontuação das dinâmicas internas da ADL Week 2026.

## Objetivo técnico

- HTML, CSS e JavaScript puros
- Funcionamento offline, sem backend ou APIs externas
- Estado persistido no `localStorage`
- Interface otimizada para notebook e projetor

## Execução

Quando o site estiver implementado, bastará abrir `index.html` em um navegador moderno.

## Publicação

O projeto está preparado para ser versionado no GitHub e publicado posteriormente com GitHub Pages.
